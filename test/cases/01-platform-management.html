TC-01-01 首次安装自动生成内置平台
待执行
Given 用户首次安装插件，本地存储中无任何平台数据
When 插件初始化完成（background 的 init 执行）
Then 自动生成"网页"平台，包含 DeepSeek、豆包、千问、Kimi 四个网页模型，每个模型有正确的 webUrl
And 自动生成"阿里百炼""智谱""深度求索""月之暗面""Ollama" 五个 API 平台，模型列表为空
And 每个平台拥有唯一的 plt-* 格式 ID
TC-01-02 添加自定义 API 平台
待执行
Given 用户打开 Dashboard 模型配置页，已有内置平台
When 用户点击"添加平台"，填写平台名称 "MyAPI"、BaseURL "https://api.test.com"、APIKey "sk-test123"，点击确认
Then 平台列表出现 "MyAPI" 平台卡片
And 平台详情区显示 BaseURL 为 "https://api.test.com"，APIKey 已保存
And 平台的 models 数组为空，等待用户添加模型
TC-01-03 平台名称重复被阻止
待执行
Given 已存在名为 "MyAPI" 的平台
When 用户再次尝试创建同名平台 "MyAPI"
Then 系统提示"该平台已存在"，创建操作失败
And 平台列表保持不变，未产生新数据
TC-01-04 为 API 平台添加模型
待执行
Given 用户选中 "MyAPI" 平台，该平台当前无模型
When 用户点击"添加模型"，输入模型编码 "gpt-4o"，点击确认
Then 该平台模型列表出现 "gpt-4o"，拥有唯一的 model-* 格式 ID
And 模型默认为启用状态（enabled: true）
TC-01-05 模型编码重复被阻止
待执行
Given "MyAPI" 平台下已有模型 "gpt-4o"
When 用户再次尝试添加模型编码 "gpt-4o"
Then 系统提示"模型编码已存在"，添加操作失败
And 模型列表保持不变
TC-01-06 切换模型启用/禁用状态
待执行
Given "MyAPI" 平台下模型 "gpt-4o" 当前为启用状态
When 用户关闭 "gpt-4o" 的启用开关
Then 模型变为禁用状态（enabled: false）
And 在会话创建时的模型选择器中不再显示该模型
And 再次点击开关，模型恢复启用状态
TC-01-07 删除平台
待执行
Given 系统存在多个平台（含内置 + 自定义）
When 用户选中某自定义平台并点击"删除"
Then 该平台从列表中移除，其下所有模型一并删除
And 其他平台数据不受影响
TC-01-08 删除唯一平台被阻止
待执行
Given 系统仅剩 1 个平台
When 用户尝试删除该平台
Then 系统提示"至少需要保留一个平台"，删除操作失败
And 该平台仍然存在
TC-01-09 网页平台不可添加模型
待执行
Given 用户选中内置"网页"平台（isWeb: true）
When 用户尝试为该平台添加模型
Then 系统提示"网页平台不支持添加模型"，操作失败
And 网页平台的模型列表保持不变
TC-01-10 获取扁平化模型列表（含启用过滤）
待执行
Given 系统有多个平台，部分模型已禁用
When 调用 getAllModels() 获取所有模型
Then 返回扁平化数组，仅包含 enabled 的模型
And 网页模型包含 webUrl 字段，API 模型包含 baseUrl 和 apiKey 字段
And 每个模型包含 platformName、platformId、color 信息
TC-01-11 数据迁移：models 字段无效时自动修复
待执行
Given 本地存储中某平台的 models 字段为 null 或非数组
When 插件初始化（initialize 执行）
Then 自动将该平台的 models 修正为空数组 []
And 其他平台数据不受影响
