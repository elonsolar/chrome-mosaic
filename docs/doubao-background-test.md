# 测试豆包页面在后台时是否会被冻结

## 测试目的

确认：当豆包页面在后台时，Mosaic 扩展是否能收到豆包的回复。

## 测试步骤

### 1. 准备工作

确保：
- Mosaic 扩展已安装并启用
- 豆包页面已打开（https://www.doubao.com/chat/）

### 2. 测试方法

**方法1：后台测试**
1. 在 Mosaic 中发送消息到豆包
2. **立即切换到其他页面**（让豆包页面到后台）
3. 等待 40-60 秒
4. 切换回豆包页面
5. 检查：豆包是否回复了？

**方法2：前台测试（对照组）**
1. 在 Mosaic 中发送消息到豆包
2. **保持豆包页面在前台**
3. 等待 40-60 秒
4. 检查：豆包是否回复了？

### 3. 预期结果

- **如果后台时豆包不回复**：页面被冻结
- **如果前台时豆包回复**：页面正常工作
- **如果后台时豆包也回复**：问题已解决

## 注意事项

- 测试时不要关闭任何页面
- 不要刷新豆包页面
- 不要打开开发者工具（这会影响测试）
