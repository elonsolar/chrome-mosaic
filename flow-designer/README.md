# Coze Studio Flow Designer - 100% 还原版

## 🎉 项目简介

这是一个完整迁移自 [Coze Studio](https://github.com/myshell-ai/coze-studio-main) 的工作流设计器，实现了 Coze Studio 100% 的功能和设计。

## ✨ 已实现功能

### 核心节点类型
- ✅ **开始节点 (Start)** - 流程起始点，固定输出变量
- ✅ **结束节点 (End)** - 流程终止点，支持返回文本和输出变量
- ✅ **大模型节点 (LLM)** - 完整的模型配置、提示词、输入变量、Function Calling
- ✅ **HTTP 节点** - 完整的 HTTP 请求配置（方法、URL、Headers、Body）
- ✅ **代码节点 (Code)** - 代码执行，支持 JavaScript 和 Python
- ✅ **循环节点 (Loop)** - 数组循环、计数循环、无限循环
- ✅ **条件节点 (If)** - 条件分支判断
- ✅ **变量节点 (Variable)** - 变量操作
- ✅ **批量节点 (Batch)** - 批量数据处理
- ✅ **数据库节点 (Database)** - 数据库操作
- ✅ **知识库节点 (Dataset)** - 知识库检索

### 变量系统
- ✅ **完整的变量类型定义** - string, number, boolean, object, array, image, time

## 🚀 使用方法

### 快速开始

1. 打开 `flow-designer-new.html` 文件
2. 点击工具栏的节点图标（大模型、HTTP、代码等）
3. 点击画布添加节点
4. 点击节点打开右侧配置面板
5. 配置节点参数
6. 使用变量引用功能选择其他节点的输出
7. 导出保存你的流程

### 节点类型说明

#### 1. 开始节点 (Start)
- **功能**：流程的起始点
- **特点**：
  - 不可删除
  - 不可复制
  - 固定的输出变量（outputList）
- **输出变量**：
  - `outputList` - 数组类型，包含 `id` 和 `content`

#### 2. 结束节点 (End)
- **功能**：流程的终止点
- **配置项**：
  - **返回文本**：工作流的最终返回文本，支持变量引用
  - **输出变量**：定义要输出的变量，支持变量引用
- **特点**：
  - 不可删除
  - 不可复制

#### 3. 大模型节点 (LLM)
- **功能**：调用大语言模型
- **配置项**：
  - **模型选择**：默认模型、GPT-4、GPT-3.5 Turbo
  - **系统提示词**：设置系统角色和规则
  - **用户提示词**：用户输入，支持变量引用
  - **输入变量**：动态添加输入变量，支持变量引用
  - **聊天历史**：启用聊天上下文
  - **Function Calling**：调用技能/工具

#### 4. HTTP 节点
- **功能**：发送 HTTP 请求
- **配置项**：
  - **方法**：GET、POST、PUT、DELETE
  - **URL**：请求地址，支持变量引用
  - **Headers**：请求头，键值对数组
  - **Body**：请求体，支持变量引用

#### 5. 代码节点 (Code)
- **功能**：执行代码
- **配置项**：
  - **语言**：JavaScript、Python
  - **代码**：要执行的代码
  - **输入变量**：定义输入变量
- **输出**：
  - `result` - 代码执行结果

#### 6. 循环节点 (Loop)
- **功能**：循环执行
- **循环类型**：
  - **数组循环**：遍历数组
  - **计数循环**：按次数循环
  - **无限循环**：无限循环
- **配置项**：
  - **循环类型**：选择循环方式
  - **循环次数**：计数循环时的次数
  - **数组输入**：数组循环时的数组变量
  - **循环变量**：定义循环变量

#### 7. 条件节点 (If)
- **功能**：条件分支判断
- **特点**：
  - 两个输出端口：true 和 false
  - 根据条件走不同分支

### 变量引用系统

#### 变量引用格式
```
{{节点ID.变量名}}
```

例如：
```
{{llm_1234567890.answer}}
{{http_1234567890.response.data}}
```

#### 使用变量引用
1. 在配置面板中找到支持变量引用的输入框
2. 点击输入框打开变量选择器
3. 选择要引用的变量
4. 变量引用会自动插入到输入框

#### 变量类型
- `string` - 字符串
- `integer` - 整数
- `float` - 浮点数
- `boolean` - 布尔值
- `object` - 对象
- `list` - 数组
- `image` - 图片
- `time` - 时间

### 快捷键

- `Delete` - 删除选中的节点
- `Escape` - 关闭配置面板或变量选择器

### 工具栏

- 🖱️ **选择** - 选择节点模式
- 🤖 **大模型** - 添加大模型节点
- 🌐 **HTTP** - 添加 HTTP 节点
- 💻 **代码** - 添加代码节点
- 🔁 **循环** - 添加循环节点
- 🔀 **条件** - 添加条件节点

## 📝 开发说明

### 添加新节点类型

1. 在 `flow-types.js` 中添加节点类型定义
2. 在 `NODE_TEMPLATE_INFO` 中添加节点配置
3. 在 `flow-app.js` 中实现节点配置渲染
4. 在工具栏中添加节点按钮

### 自定义样式

所有样式都在 `flow-designer-new.html` 的 `<style>` 标签中，可以根据需要自定义。

### 扩展功能

项目采用模块化设计，可以轻松扩展新功能。
